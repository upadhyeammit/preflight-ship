## Consumer Impact

- Who consumes this API?
- Which consumers can break?
- How will consumers react to changes?

## Failure Handling

- What happens if the API is unavailable?
- What happens if latency doubles?
- What happens if downstream services fail?

## Contract Evolution

- Can new fields be added safely?
- Can fields be removed?
- Is versioning required?

## Operational Visibility

- How will failures be detected?
- What metrics are required?
- What logs are required?
