## Purpose

Capture lessons learned after feature implementation.

Improve future discovery, design, and delivery workflows.

---

## When to Use

After implementation is complete.

Workflow:

Implementation → Retrospective → Lessons Learned → Skill Improvement

---

## Phase 1 - Outcome Review

Review what was delivered against the original discovery and delivery plan.

Determine:

- What worked well?
- What did not work well?
- Were requirements met?
- Were acceptance criteria satisfied?

---

## Phase 2 - Assumption and Unknown Analysis

Identify:

- Which unknowns were missed during discovery?
- Which assumptions were incorrect?
- Which risks materialized?
- Which risks did not materialize?

---

## Phase 3 - Process Review

Evaluate the engineering workflow:

- Was discovery sufficient?
- Was architecture review effective?
- Was delivery planning accurate?
- Were tasks appropriately sized?
- Were dependencies identified correctly?

---

## Phase 4 - Improvement Identification

Determine improvements for:

- Engineering Discovery Skill (`engineering-discovery.md`)
- Architecture Review Skill (`architecture-review.md`)
- Delivery Planning Skill (`delivery-planning.md`)
- Relevant checklists in `Checklists/`
- Engineering Lifecycle Framework (`Frameworks/Engineering Lifecycle Framework.md`)

Capture actionable updates for `Lessons-Learned/`.

---
